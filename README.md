# General Conference Talk Picker — V2

The mobile-first rebuild of the General Conference Talk Picker: draw, browse, study and track 4,050 General Conference talks (1971–present). Built with Expo (React Native + Expo Router) so one codebase ships to iOS, Android and the web. Live on the web at [gctalkpicker.app](https://gctalkpicker.app); the iOS app is in App Store review.

## Run it

```bash
npm install
npx expo start --web     # web at http://localhost:8081
npx expo start           # native: open the exp:// URL in Expo Go on a phone
```

Ship the web build with `npm run deploy:web` (never a bare `expo export`; see the handoff for the Cloudflare reason). iOS builds go through EAS (`eas build` / `eas submit`). Kingston runs those in their own Terminal because they prompt for Apple credentials.

## Layout

- `src/app/`: routes. The tabs live under `(tabs)/`; every other screen must be a sibling `Stack.Screen` in `src/app/_layout.tsx`.
- `src/components/`, `src/components/ui/`: app chrome and design-system primitives.
- `src/hooks/`: auth, talk status, draw scope and draw reveal.
- `src/constants/theme.ts`: brand tokens. `src/constants/session-taxonomy.ts`: session mapping.
- `src/data/`: the talks dataset (generated by `scripts/generate-talks-data.js`, don't hand-edit).
- `supabase/`: SQL that gets pasted into the Supabase SQL Editor by hand (`schema.sql`, `avatars-storage.sql`, `social.sql`). There's no Supabase CLI project.
